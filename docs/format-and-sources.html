Format and source notes

Verified for the regular 2026 TOEFL iBT format, 11 October 2026. The redesigned format began 21 January 2026. This app is independently authored and is not an official ETS simulator.

The order of sections is Reading → Listening → Writing → Speaking. The app groups task types in ETS’s listed order as a training route. Reading and Listening on the authentic test are multistage adaptive; actual item counts, placement and timing can vary. The linear practice form in this app has the base totals but no adaptive calibration.

Primary verification:

  • ETS current content and structure
  • ETS updated test overview, section sequence and base table
  • ETS 2026 test specifications
  • ETS Writing task descriptions

The specifications describe 10 sentence-building items, one email and one discussion; seven repetition items and four interview items. The local 2026 preparation source also describes a 6/7/10-minute Writing sequence, 8–12-second repetition windows and 45-second interview responses. The app uses these as practice targets. General standalone activity times, such as a three-minute missing-words passage, are independent training defaults rather than ETS per-activity promises.

Uploaded HTML inspection

Inspected the original TOEFL_2026_Complete_the_Words.html attachment recovered from the referenced chat. It contained 53 sets and mixed original/PDF-derived wording. pieceMarkup created a single input for each missing sequence, rendering spaced underscores as its placeholder. Entering any character removed the entire placeholder. Its width did not solve the visual count problem; navigation was limited.

The new React component generates one persistent input for each missing letter, using the answer length as its count. Blank editing preserves indices, supports suffixes, arrow navigation, Backspace/Delete, Home/End and bounded paste. The new app does not carry over the old copied question library.

Read-only project PDFs inspected

  • Complete_the_Words_Practice_Questions_visible.pdf: paragraph cloze exercises and visible letter gaps. Considered exact gap lengths, preserved prefixes/suffixes and the usefulness of context-rich passages. No paragraphs or answer keys copied.
  • Essential exercise toefl 2026.pdf: frequent verbs, function words, connectors and fill-in practice with an answer key. Informed mixing grammatical and content words in original cloze passages; no exercise text copied.
  • TOEFL_Preparation_Book_2026_2027_3_TOEFL_iBT_Practice_Tests_and.pdf: contents, 2026 overview, task counts and practice timing. Treated as a secondary source; did not adopt its claimed adaptive routing threshold. No tests/transcripts copied.
  • The_Official_Guide_to_the_TOEFL_iBT®_Test,_Pocket_Edition_z_library.pdf: 2026 table of contents and introductory guidance on reading, listening, writing, speaking, independent evidence and linear practice. No protected practice content, media download or answer key redistributed.
  • Building Grammar Skills for TOEFL.pdf: inspected its image-based opening pages; text extraction produced no usable grammar content. It was not used to author or reproduce questions.

All 60 activity prompts, passages, scripts, choices, explanations and samples in the shipped bank were newly written for this app. Audio is newly synthesized from those scripts. Uploaded/reference files remain unchanged and are excluded from the ZIPs.

Objective correctness is a raw practice percentage. Writing and speaking use checklist-based self-assessment. No automated or converted TOEFL score is offered. TOEFL and TOEFL iBT are trademarks of ETS; their names are used only to identify the test for which this independent material is intended.
