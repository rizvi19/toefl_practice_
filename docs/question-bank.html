Version 1 question bank

Use UTF-8 JSON. Start from example-bank.json, import via the Question bank screen and inspect its preview. Root structure:

{"version":1,"name":"My original practice","items":[]}

Give each activity a unique id consisting of letters, numbers, underscores or hyphens, a title, and one of the following exact type values. IDs are unique across built-in and imported activities. Imported questions are personal; edit the built-in source bank to share them through the published site.

Common optional fields: seconds (8–7,200 seconds, a standalone training limit), audio (safe relative path such as ./audio/my-clip.wav, .mp3 or .ogg), difficulty, pack, context. Local import cannot automatically upload audio to a server. Put shared audio in the project’s public/audio/ folder and rebuild. Without an audio path, the script is read by browser text-to-speech. Audio assets must use safe filenames (letters, numbers, underscore, hyphen) and the audio directory; remote URLs and path traversal are rejected.

Fixed letter slots

pieces alternates plain text and blank objects. Each answer character creates one permanent slot; do not put underscores in the answer. A post suffix is optional. Preserve whitespace in the strings between words.

{
  "id":"my-cloze-1","type":"complete-words","title":"A short observation","seconds":60,
  "pieces":["Tiny ",{"pre":"ani","answer":"mal","post":"s","explanation":"The plural word is animals."}," live in this habitat."]
}

Answer letters are alphabetic and 1–20 characters long. Scoring compares the missing letters case-insensitively; the fixed prefix/suffix is not entered by the learner. Use sufficient context to make the answer unambiguous.

Multiple choice

All Reading/Listening choice tasks have questions: 1–10 objects. Every object needs stem, four options, a zero-based answer from 0 to 3 and a useful explanation.

{
  "id":"my-listening-1","type":"choose-response","title":"A polite request",
  "script":"Could you close the window?","seconds":40,
  "questions":[{"stem":"Choose the best reply.","options":["Of course.","Last summer.","A blue notebook.","The course has ended."],"answer":0,"explanation":"The speaker requests an action; the first reply agrees."}]
}

Reading uses passage instead of script. Longer listening tasks can contain several questions. Match format expectations when authoring: conversations and announcements often have two questions, academic talks four, academic passages five. The validator permits smaller/larger study sets.

Sentence building

chunks contains selectable words/phrases. solution lists their indices in correct order. Repeated chunks need separate indices. Distractors are allowed: solution need not use every chunk. Include an explanation of the grammar and, optionally, alternatives as complete accepted strings joined with a space between chunks.

{
 "id":"my-sentence-1","type":"build-sentence","title":"An embedded question",
 "prompt":"Where is the meeting?",
 "chunks":["the meeting","Could you tell me","is","where","?"],
 "solution":[1,3,0,2,4],
 "explanation":"Embedded questions use subject–verb order."
}

Use punctuation as separate chunks or attach it consistently. Grading joins selected chunks with spaces and normalizes case/whitespace. It does not rewrite punctuation or accept alternate grammar unless explicitly listed.

Writing and speaking

checklist is an array of 1–10 self-review statements. Writing tasks also need an original sample; samples are shown only after submission or in the report. repeat needs script and responseSeconds (8–12). interview uses 45 response seconds by default; include a script containing the interviewer’s question for audio. No automatic linguistic score is generated.

{
 "id":"my-repeat-1","type":"repeat","title":"Library directions",
 "prompt":"Listen, then repeat the sentence.",
 "script":"The reading room is upstairs.","responseSeconds":8,"seconds":30,
 "checklist":["I repeated every word.","My speech was clear."]
}

Import limits: 5 MB per file, 1–1,000 activities, titles up to 200 characters, scripts/prompts/passages/samples up to 30,000 characters, no executable HTML. React renders text as text. Malformed imports leave the current library unchanged. Duplicate IDs are rejected, not silently replaced. Export the library to share a complete bank. Keep ownership/licensing of all content in mind before distributing it.
