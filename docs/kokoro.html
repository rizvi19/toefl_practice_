YOUR PC · YOUR VOICES

Use Kokoro for Listening.

For the easiest setup: open Practice Studio → Settings → Audio source → Kokoro (in this browser), then press Play audio. Your browser downloads about 118 MB once and creates only the audio you practice. No helper is required. The steps below are the optional way to reuse an existing Python installation.

Practice Studio can create an activity’s audio when you press Play. Run the small helper on the same PC as your browser. Your existing Kokoro installation supplies the voices; the website keeps your scores and progress as usual.

Download local helper

This download contains the helper and activity scripts only. It includes no Python, PyTorch, models or installers. It never generates the full activity bank automatically.

Your installation stays on your PC

Closing the website or chat does not uninstall Kokoro. The Python model and browser model are separate: browser cache can be cleared or evicted, while your installed model stays in its installation folder. The local helper must be running to use that installation. For automatic startup, place a shortcut to your helper launcher in the Windows Startup folder (Win+R, shell:startup). On a PC configured with Kokoro Studio, use its desktop shortcut.

Start with your existing installation

  1. Extract the ZIP to a small folder on a drive with room for a 20 MB audio cache. Keep the files together.
  2. Double-click Launch-Kokoro.cmd. Supply your existing Kokoro environment’s python.exe, model folder and ffmpeg.exe if asked. The model folder must contain config.json, kokoro-v1_0.pth and voices/af_heart.pt plus voices/am_michael.pt. A LocalTTS folder containing models/kokoro also works.
  3. Keep the helper window running. In Practice Studio, open Settings → Audio source → Kokoro (local helper), then Check connection.
  4. If your browser asks for local network access, allow this site to connect to your helper. See Chrome’s explanation. No browser security settings need to be disabled.
  5. Choose a Listening activity and press Play audio. The first missing recording takes a little time to generate; cached recordings play directly.

What you need already installed

Kokoro with its American English language dependencies, CPU PyTorch, its local model and both voices, and FFmpeg with MP3 encoding. This helper reuses these files and loads the model offline. It does not install or download anything. If your existing setup uses a different model layout, point the launcher to the model folder rather than copying model files.

Keep storage small

The helper creates 24 kHz mono MP3 at 48 kbps: roughly 360 KB per minute. Only the activity you play is generated. The default 20 MB cache removes older helper-generated MP3s when needed; it preserves the pilot recording and current activity. Original website audio, your models and personal files are untouched.

Conversations use af_heart for Woman and am_michael for Man, with pauses between turns. Speaker labels are not spoken. Examination audio still plays once, questions unlock after completion, and transcripts remain restricted.

If you prefer a terminal

From the extracted helper folder, use your own existing paths:

& 'D:\LocalTTS\venv\Scripts\python.exe' '.\tools\kokoro-local.py' --serve --allow-generation --kokoro-home 'D:\LocalTTS' --ffmpeg 'C:\path\to\ffmpeg.exe'

Add --cache-mb 10 for a smaller cache. Close the helper window or press Ctrl+C to stop it. Download an updated helper if the website’s activity scripts change.

If the helper is unavailable, the site falls back to browser speech. Original recordings and the shared Kokoro pilot play without a helper. Local Kokoro works on the PC running it; it does not provide a shared voice service to other visitors or phones.
